# H-Mobility 자율주행 심화과정 — 조향 제어 및 인지 시스템

현대자동차그룹 **H-Mobility Class 자율주행 심화과정** 경진대회에서 개발한 자율주행 소프트웨어입니다.
카메라 기반 차선 인식부터 경로 생성, 조향 제어, 신호등 인식까지 **주행 코드 전반을 단독으로 설계·구현**했습니다.

> 소형 자율주행 차량을 팀 단위로 조립하고 실제 트랙에서 주행시키는 대회로,
> 인지·판단·제어·통신이 하나의 시스템으로 맞물려 동작해야 완주가 가능했습니다.

---

## 🏗 시스템 구성

```
카메라 → [차선 인식] → [경로 생성] → [조향·속도 제어] → 모터
              ↓             ↓              ↑
         신호등 인식     버드아이뷰      상태머신
                        + ROI 제한   (대기/주행/감속/정지)
```

ROS2(rclpy) 기반 노드 구조로 각 단계를 분리해 메시지로 통신합니다.

| 노드 | 역할 |
|---|---|
| `lane_info_extractor_node` | 카메라 영상을 버드아이뷰로 변환하고 차선 중앙점 추출 |
| `path_planner_node` | 중앙점들로 CubicSpline 경로 생성 |
| `motion_planner_node` | 경로 기반 조향·속도 계산, 신호등/정지선 상태머신 |
| `traffic_light_detector_node` | YOLO 신호등 검출 + HSV 색 판별 |

---

## 🔧 주요 기술

- **언어/프레임워크**: Python, ROS2 (rclpy)
- **인지**: OpenCV (버드아이뷰 원근 변환, ROI 처리, HSV 색공간 분석), YOLO 객체 검출, Roboflow 라벨링
- **제어**: PID 제어기 직접 구현(비례·미분·적분), 저역통과 필터, 데드밴드, 변화율 제한, 안티 와인드업, 스탠리(Stanley) 방식
- **경로 생성**: CubicSpline 보간
- **형상관리**: Git

## 🚀 개발 과정 (조향 제어 진화)

이 저장소의 커밋 히스토리는 실제 문제 해결 과정을 그대로 담고 있습니다.

1. **기본 파이프라인** — 기존 뱅뱅 제어(±7/0)를 경로 기울기 비례 제어로 전환
2. **시야 최적화** — 버드아이뷰 + ROI로 차량 앞쪽만 보도록 lookahead 축소, 직진 안정성 확보
3. **스탠리 방식 시도** — 헤딩 오차 + 횡방향 오차(CTE) 결합 제어를 구현했으나, 직선 미세 진동과 CTE 변환계수 튜닝 난이도로 폐기
4. **PID로 회귀·재설계** — 필터 + 데드밴드 + 변화율 제한 + 안티 와인드업으로 견고하게 재구성
5. **신호등 인식 추가** — 오검출 방어 로직(녹색 연속 프레임 확인) 포함
6. **최종 튜닝** — 적분항은 구조만 유지하고 KI=0으로 확정, 필터·데드밴드만으로 안정화

> 핵심 교훈: 이론적으로 더 우아한 스탠리 방식을 알면서도, 우리 환경에서 실제로 더 견고하게 동작하는 PID로 돌아온 판단.
> **이론의 우수함보다 시스템에서의 실제 작동을 우선**했습니다.

## ⚙️ 핵심 파라미터

| 파라미터 | 의미 | 위치 |
|---|---|---|
| `STEER_KP` | 비례 게인 (반응 세기) | `motion_planner_node.py` |
| `STEER_KD` | 미분 게인 (사행 억제) | `motion_planner_node.py` |
| `STEER_KI` | 적분 게인 (좌우 쏠림 보정, 기본 0) | `motion_planner_node.py` |
| `SLOPE_FILTER_ALPHA` | 저역통과 필터 계수 | `motion_planner_node.py` |
| `STEERING_RATE_LIMIT` | 한 틱당 조향 변화 제한 | `motion_planner_node.py` |
| `LOOKAHEAD_POINTS` | 전방 주시 거리 (시야) | `motion_planner_node.py` |

튜닝 순서: **필터 α → KD → KP** (KP와 KD는 시소 관계 — 반응성을 키우고 그때 생기는 진동을 미분으로 억제)

## 📁 저장소 구조

이 저장소는 전체 ROS2 워크스페이스 중 **직접 작성한 핵심 소스 코드**만 담고 있습니다.
빌드 산출물(`build/`, `install/`, `log/`), 학습 이미지 데이터셋, 주행 로그 등은
용량 문제로 `.gitignore` 처리하여 제외했습니다.

```
ros2_ws/
├── src/
│   └── interfaces_pkg / ...      # 커스텀 메시지 정의
│   └── <package>/
│       ├── lane_info_extractor_node.py    # 차선 인식
│       ├── path_planner_node.py           # 경로 생성
│       ├── motion_planner_node.py         # 조향·속도 제어
│       ├── traffic_light_detector_node.py # 신호등 인식
│       └── lib/
│           └── camera_perception_func_lib.py  # 영상 처리 함수
├── docs/
│   └── 버전_매뉴얼.md   # PID×Stanley, 시야범위 비교 실험 설계
├── .gitignore
└── README.md
```
